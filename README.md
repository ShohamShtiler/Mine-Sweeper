# 🧨 Minesweeper

A classic Minesweeper game built in vanilla JavaScript, HTML & CSS — featuring multiple difficulty levels, smart expansion logic, lives system, and a fun UI.

---

## 🎮 Game Features

- ✅ Left click to reveal a cell
- 🚩 Right click to flag/unflag suspected mines
- 💣 Game over on clicking a mine (unless lives are left)
- 🧠 Smart expansion for zero-neighbor cells
- 😃 Smiley button to reset the game
- ❤️ Lives system – 3 lives per game
- 🧩 First click is always safe
- 📊 3 difficulty levels:
  - Beginner: 4x4 (2 mines)
  - Medium: 8x8 (14 mines)
  - Expert: 12x12 (32 mines)

---

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript (Vanilla)
